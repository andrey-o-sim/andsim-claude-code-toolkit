# andsim-claude-code-toolkit

## Output language of commands and skills

Every command and skill in this repo writes its output in English: reports, status lines, stop messages and questions to the user. Fixed phrases that a command prints (for example `PR is ready to be merged`) are English too.

Do not add lines such as "Answer in Russian" to a command or skill. If a user wants another language, they ask for it in the session.
